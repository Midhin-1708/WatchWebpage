# VELARO

VELARO is a clean Vite + React luxury watch storefront implemented entirely with JSX. The project follows the requested structure: reusable components live in `src/components`, route-level screens in `src/pages`, cart state in `src/context`, product records in `src/data`, utility hooks in `src/hooks`, and the shared shell in `src/layouts`.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The project intentionally contains no Manus-specific files, TypeScript configuration, server code, shared backend scaffolding, or template-only UI directories.
